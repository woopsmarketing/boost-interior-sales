Scene header lockup (eyebrow, one-sentence headline, sub line) used at the top of every story scene.
```jsx
<SceneHeader step="02 / 09" title="조건에 맞는 우리 업체 시공 사례를 바로 보여줍니다." sub="지역 · 평형 · 공사 범위가 비슷한 사례를 카드로 추천합니다." />
```
Sizes xl (hero) / lg (scene) / md. Uses word-break: keep-all for Korean line breaks.
