Pill-shaped CTA button; use for "도입 상담 신청" and other conversion actions — one primary per view.
```jsx
<Button variant="primary" size="lg" arrow>도입 상담 신청</Button>
<Button variant="secondary">데모 보기</Button>
```
Variants: primary (blue), secondary (white + border), ghost (blue text), onImage (white over photo), dark (navy). Sizes sm 36 / md 48 / lg 56. `arrow` adds a literal → that nudges on hover.
